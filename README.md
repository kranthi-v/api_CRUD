# API CRUD Operations

## 📌Project Description
This project is a REST API that performs CRUD(Create, Read, Update, Delete) operations using Django REST Framework.

## Technologies Used
- Python
- Django
- Django REST Framework

## Installation
1. Clone repository
2. Install Dependencies
```
pip install django
pip install djangorestframework
```
3. Run migrations
```
python manage.py migrate
```
4. Start server
```
python manage.py runserver
```
